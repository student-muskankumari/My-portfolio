# Muskan Kumari — Portfolio v2

A 3D interactive developer portfolio built with React, Three.js, Framer Motion, and Tailwind CSS.

Live tagline: **Data Analyst · ML Enthusiast · Building Intelligent Systems**

---

## Features

- **3D hero** — animated particle sphere + wireframe icosahedrons via React Three Fiber
- **Custom cursor** — cyan dot + lagging violet ring that expands on hover (auto-disabled on touch)
- **Smooth scrolling** — Lenis-powered buttery scroll with hash-link interception
- **Loading animation** — animated boot screen with progress bar
- **Tilt cards** — project cards respond to mouse position with real 3D rotateX/rotateY
- **Scroll-spy nav** — active link highlight tracks your scroll position
- **Glass morphism + grain overlay** — premium dark UI with SVG noise texture
- **Reveal animations** — Framer Motion viewport reveals on every section
- **Responsive** — breakpoint-tuned for mobile through 4K
- **Reduced motion** — respects `prefers-reduced-motion`
- **SEO meta + OG tags** — ready for social sharing

## Tech stack

- **React 18** + **Vite 5** — fast dev server, lean bundles
- **Tailwind CSS 3** — custom theme with neon cyan/violet/pink palette, Syne + Space Mono + Inter fonts
- **Three.js** + **@react-three/fiber** + **@react-three/drei** — 3D hero scene
- **Framer Motion** — reveal animations, tilt, loader transitions
- **Lenis** — smooth scrolling
- **Lucide React** — icons

## Ask AI widget (RAG-powered chat)

A floating "Ask AI about my work" button (bottom-right) lets visitors ask natural-language questions about projects, skills, and experience. Answers are generated by Groq (llama-3.1-8b-instant) using a RAG pipeline built from scratch.

### How it works

1. **Offline indexing** (`npm run build:rag`): `scripts/buildRagIndex.js` extracts text from `portfolio.js`, `kronos_report.md`, and `Cuemath_Studio_Full_Report.docx`, chunks it into ~300-token segments, embeds every chunk with `Xenova/all-MiniLM-L6-v2` (a local sentence-transformer — no API key needed), and writes `src/data/ragIndex.json` to the repo.

2. **Runtime** (`api/ask-ai.js`): A Vercel serverless function embeds the user's question with the same model, computes cosine similarity against the pre-built index, selects the top-5 most relevant chunks, and sends them as context to Groq's chat API. The Groq API key never leaves the server.

### Regenerate the index

If you update `portfolio.js` or the project reports, re-run:

```bash
npm run build:rag
```

Then commit the updated `src/data/ragIndex.json`.

### Environment variable

| Variable | Where | Value |
|---|---|---|
| `GROQ_API_KEY` | Vercel → Project → Settings → Environment Variables | Your key from console.groq.com/keys |

Copy `.env.example` → `.env.local` and fill in the key for local dev with `vercel dev`.

## Run locally

Requires Node.js 18 or newer.

```bash
# 1. Install dependencies
npm install

# 2. Start dev server (opens http://localhost:5173)
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build locally
npm run preview
```

### Local dev with the AI widget

The AI widget calls `/api/ask-ai`. To test it locally:

```bash
# Terminal 1 — Vercel dev server (handles /api/*)
npx vercel dev

# Terminal 2 — Vite dev server (proxies /api/* to port 3000)
npm run dev
```

## Customization

**All content lives in `src/data/portfolio.js`.** Edit that single file to change:

- Your name, tagline, email, links
- About paragraphs and stats
- Skills (4 categories, edit `level` 0–100 for progress bars)
- Projects — add/remove entries; each project supports: `title`, `subtitle`, `blurb`, `impact`, `stack`, `github`, `live`, `icon` (from `lucide-react`), `accent` (`cyan` / `violet` / `pink`), `highlight` (bool, makes card 2-col wide)
- Experience timeline
- Certificates
- Contact channels

**Replace the placeholder resume:** Drop your real PDF at `public/Muskan_Kumari_Resume.pdf` (keep the filename) and the Download button will serve it.

**Change colors:** Edit `tailwind.config.js` under `theme.extend.colors.neon` and the CSS variables in `src/styles/globals.css`.

**Change fonts:** Swap the Google Fonts URL in `index.html` and update `tailwind.config.js` under `theme.extend.fontFamily`.

## Deploy to Vercel

1. Push this project to a GitHub repo.
2. Go to [vercel.com/new](https://vercel.com/new), import the repo.
3. Vercel auto-detects Vite. Accept defaults:
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. **Add the environment variable** `GROQ_API_KEY` in Project → Settings → Environment Variables.
5. Click Deploy. First build takes about 60 seconds.

> The AI widget's cold start (first request after inactivity) may take ~15–20 s while the ONNX embedding model downloads. Subsequent requests within the same warm window are fast (< 2 s).

## Deploy to Netlify

1. Push to GitHub.
2. Go to [app.netlify.com](https://app.netlify.com), New site from Git.
3. Build command: `npm run build`
4. Publish directory: `dist`
5. Deploy.

## Performance notes

- Three.js scene lazy-loaded with `Suspense` — doesn't block first paint
- Device pixel ratio capped at 1.75 to stop thermal throttling on high-DPI laptops
- Grain texture is an inline SVG data URI (no network request)
- Fonts preconnected and display-swapped
- Animations pause for users with `prefers-reduced-motion: reduce`
